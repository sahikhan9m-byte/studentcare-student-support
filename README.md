# StudentCare – Student Support Platform 🎓

StudentCare is a student support platform designed to help students manage their academic life, improve their skills, plan their studies, and explore career opportunities.

The website provides useful sections for students to understand common challenges and find helpful resources for their personal and academic growth.

## 🌐 Project Overview

StudentCare aims to make student life easier by providing a simple and user-friendly platform where students can explore study resources, manage their time, discover career opportunities, and share their problems.

## ✨ Features

- **Dashboard:** Welcome section with an overview of the platform.
- **Student Challenges:** Information about study pressure, time management, career confusion, financial problems, stress, and lack of skills.
- **Study Planner:** A weekly study schedule from Monday to Sunday.
- **Career & Opportunities:** Resources for learning IT skills, creating resumes, finding internships, and building portfolios.
- **Student Support:** Contact form where students can describe their problems.
- **Responsive Design:** A clean and modern website layout.

## 🛠️ Technologies Used

- HTML5 – For website structure.
- CSS3 – For styling, layout, colors, and animations.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
5. Explore the StudentCare website.

## 🎯 Project Objective

The main objective of StudentCare is to support students in their academic journey by helping them organize their studies, identify common challenges, develop practical skills, and explore future career opportunities.
